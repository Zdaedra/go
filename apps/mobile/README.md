# Дебюты Го 9×9 — мобильное приложение

Expo / React Native приложение-тренажёр дебютов 9×9. Спецификация:
`docs/app-spec.md` в корне репозитория.

## Запуск

```sh
cd apps/mobile
npm install
npm start          # Expo dev server; открыть в Expo Go на телефоне
npm test           # тесты движка (чистый Node, без RN)
npm run typecheck  # tsc --noEmit
```

## Что уже работает (MVP, этап 1)

- **Режим игры («лайв»)** — вкладка «Игра»: ставишь камни за обе стороны
  (переключатель «Я играю за ⚫/⚪»), приложение после каждого хода:
  - опознаёт дебют и ветку («Дебют: Curveball — ветка 1»),
  - при нескольких кандидатах показывает до трёх подсказок-«призраков»,
  - на финальной позиции диаграммы рисует буквы A, B, C… и треугольники
    на их координатах из базы,
  - на ход вне базы отвечает «Такого дебюта в базе нет»,
  - работает в любой ориентации доски (8 симметрий), взятия по правилам.
- **Режим обучения** — вкладка «Обучение»: список дебютов текстом по
  семействам; карточка дебюта с ветками и проигрыванием линии.
- **Настройки** — темы доски (кайя/тёмная/бумага) и темы камней
  (сланец-ракушка/матовые/плоские) выбираются независимо; живой превью.

## Структура

```
src/engine/    board.js (взятия), symmetry.js (8 симметрий, канонизация),
               identify.js (опознавание по data/branches.json)
src/data/      branches.json (копия data/openings/9x9/branches.json),
               names.ts (словарь названий — авторские, менять здесь)
src/theme/     boardThemes.ts, stoneThemes.ts, ThemeContext.tsx
src/components/Goban.tsx (SVG-доска: дерево, объёмные камни, буквы, метки)
src/screens/   PlayScreen, LearnScreen, OpeningScreen, SettingsScreen
test/          engine.test.cjs — прогоняется обычным Node
```

Движок написан на CommonJS специально: те же файлы исполняются и в
React Native (Metro), и в Node для тестов.

При обновлении базы: перегенерировать `data/openings/9x9/branches.json`
(скрипты в `scripts/`) и скопировать в `src/data/branches.json`.

## Также работает

- **Тап по букве продолжения** на доске: ставится камень этого варианта,
  опознавание тут же называет ветку, в которую он ведёт.
- **Регистрация по email**: экран входа (email → 6-значный код) через
  `apps/mobile-backend`; адрес сервера — `EXPO_PUBLIC_API_URL`. Без
  сервера доступен гостевой режим (для разработки).
- **Лимит бесплатного тарифа**: 3 *разных* опознанных дебюта в день
  (повтор дебюта не тратит слот). Сверх лимита название скрывается 🔒 и
  открывается пейволл «$5/мес». Счётчик локальный (AsyncStorage) +
  зеркалится на бэкенд при наличии токена.
- **Пейволл**: экран подписки; покупка — заглушка до подключения
  RevenueCat (в dev-сборке подписку можно включить кнопкой).
