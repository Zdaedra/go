# Дизайн-эталон приложения

## Главный экран

`screen1.html` — веб-реплика эталонного экрана (рендерить Chromium'ом,
окно 854×1960, обрезать до 854×1844); `replica_v13.png` — утверждённый
рендер. Реплика сведена с макетом заказчика итеративным «консилиумом»
из двух независимых ревьюеров (исходный макет в репозиторий не
коммитится).

## Остальные экраны (`screens/`)

Восемь экранов приложения в том же стиле: тренировка (дашборд и
сессия), список дебютов, карточка дебюта, каталог задач, настройки,
вход по почте, пейволл. Общая дизайн-система — `screens/app.css`,
отрисовка доски — `screens/board.js`; `scr-*.png` — утверждённые
рендеры. Рендер: тот же Chromium-конвейер, что и для главного экрана.

Набор прошёл тот же двухсудейный консилиум с пиксельными замерами
против макета (9 раундов). Финальные оценки обоих ревьюеров —
**9.5/10, «ship it»**: все контрольные точки совпадают с макетом в
пределах нескольких единиц RGB, оставшиеся расхождения видны только
в пиксельной пипетке.

## Токены и перенос в приложение

Токены перенесены в приложение: `apps/mobile/src/theme/uiTheme.ts`
(цвета/радиусы/шрифты), тема доски `nightLuxe` и камней `lacquer` —
дефолтные. Шрифты Playfair Display и Inter (SIL OFL) — в
`apps/mobile/assets/fonts/`.

Ключевые решения стиля (значения замерены по макету попиксельно):

- угольное поле `#121213`, остывающее к низу, с дымкой из
  перекрывающихся эллипсов (пики `#181A1A`, волнистый гребень,
  зерно только внутри полос);
- карточки «утоплены» ниже поля: `rgba(6,6,7,0.40)` + волосяная
  обводка `rgba(255,255,255,0.08)` (интерьер ≈15 против поля ≈21);
- акценты: перивинкл `#6F63DC` (полосы прогресса), лаванда
  `#8B7CF6`/`#9D8CFF` (лейблы), персик `#F0A878`;
- антиква Playfair (вес 500) для названий и числовых показателей,
  разреженные капс-лейблы;
- доска `nightLuxe`: дерево `#6F5638 → #77603F → #624B32`,
  равномерная сетка 1px, координаты снаружи слэба с обоих флангов;
- камни 0.80 клетки; лакированные белые с косым (30°) бликом;
- кольцо последнего хода: кремовое `rgba(235,200,165,0.62)` +
  тёплое внешнее свечение;
- главная кнопка: тёмный «лак» `#1A1720`, замкнутое тёплое кольцо
  (коник: роза сверху `#CE86A0`, медь справа, тёплый низ `#C98870`,
  персик слева, розово-пинковый пик на 315° `#F1A6AD`) и отдельная
  лавандовая дуга-купол `#6157AD` над кнопкой с холодной дымкой
  между дугой и кромкой.
