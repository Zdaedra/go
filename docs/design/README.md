# Дизайн-эталон приложения

`screen1.html` — веб-реплика эталонного экрана (рендерить Chromium'ом,
окно 854×1960, обрезать до 854×1844); `replica_v13.png` — утверждённый
рендер. Реплика сведена с макетом заказчика итеративным «консилиумом»
из двух независимых ревьюеров (финальные оценки 9/10 и 8.5/10 — «на
взгляд один и тот же экран»; исходный макет в репозиторий не коммитится).

Токены перенесены в приложение: `apps/mobile/src/theme/uiTheme.ts`
(цвета/радиусы/шрифты), тема доски `nightLuxe` и камней `lacquer` —
дефолтные. Шрифты Playfair Display и Inter (SIL OFL) — в
`apps/mobile/assets/fonts/`.

Ключевые решения стиля: угольный фон `#100E0D` с дымкой; карточки
`rgba(255,255,255,0.03)` с волосяной обводкой; фиолетовый акцент
`#8B7CF6` + персиковый `#F0A878`; антиква для имён/названий; разреженные
капс-лейблы; медово-ореховая доска с зерном и виньеткой; глянцевые
камни; тёплое кольцо последнего хода; круглые нижние кнопки с
градиентным кольцом.
