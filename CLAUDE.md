# Go 9×9 — тренажёр дебютов и задач

Мобильное приложение (React Native + Expo SDK 51) для тренировки Го:
опознание дебютов 9×9 по камням на доске, адаптивный тренажёр цумэго,
подписочная монетизация. Главный код — `apps/mobile`.

## Состояние проекта (передача из облачной сессии)

- **Ветка разработки: `claude/go-openings-extraction-vxunif`** (PR #1).
  Вся работа ведётся в ней.
- Дизайн: тёмный «ink & lacquer», утверждён двухсудейным консилиумом
  по пиксельным замерам против макета заказчика. Эталон —
  `docs/design/` (README со значениями, `screens/` — реплики и рендеры).
  Токены: `apps/mobile/src/theme/uiTheme.ts`; доска `nightLuxe`,
  камни `lacquer` — дефолт.
- ТЗ: `docs/app-spec.md`. Запуск на iPhone: `docs/run-ios.md`.
- Бэкенд (FastAPI + SQLite): `apps/mobile-backend` — не развёрнут;
  без него приложение работает в гостевом режиме.
- Задачи цумэго: 1039 импортированы (`data/tsumego/problems.json`),
  видимы только размеченные (~35). Идёт разметка KataGo на Vast.ai
  (бандл `scripts/mark_tsumego_katago.py`; результат вливается
  `--merge`, после чего обновить `apps/mobile/src/data/tsumego.json`).
- Дебюты: 46 дебютов / 259 диаграмм извлечены из EPUB
  (`data/openings/9x9/`), ветки и продолжения слинкованы
  (`branches.json`), опознание позиций — через канонический хэш
  8 симметрий (`apps/mobile/src/engine/`). Симметрия закреплена тестом
  `test/symmetry.test.cjs` (каждая ветка × 7 трансформаций, ~12k позиций).
- Игровой экран (сессия 2026-07-10, живые тесты на iPhone): Dynamic Type
  ограничен ×1.15 (App.tsx), safe-area отступ, заголовок ужимается;
  в неоднозначной позиции карточка показывает «Тэнгэн · N» и полный
  список кандидатов; в середине ветки книжные продолжения рисуются
  фиолетовыми точками (kind:'dot' в Goban); завершение дебюта — отдельное
  состояние «Дебют завершён ✓» (viaBook-снапшот в истории ходов),
  не путать с «Такого дебюта в базе нет».

## Команды

```bash
cd apps/mobile
npm install          # первый раз
npm test             # тесты движка (board/tsumego/adaptive) — Node, без RN
npm run typecheck    # tsc --noEmit
npx expo run:ios --device   # нативная сборка на подключённый iPhone
npx expo start       # дальше — обновления по Wi-Fi без пересборки
```

## Правила

- Движок (`src/engine/*.js`) — CommonJS, тестируется Node'ом без Expo;
  не переписывать на TS/ESM без нужды.
- Дизайн-значения (цвета, размеры камней 0.80×клетки, дерево
  `#6F5638→#77603F→#624B32`, карточки `rgba(6,6,7,0.40)`) — замерены
  консилиумом; менять только со ссылкой на `docs/design/README.md`.
- На вебе id внутри SVG глобальны на документ: любые `<Defs>` id
  делать уникальными на инстанс (см. Goban/MistBackground/PrimaryButton).
- В RN процентные padding'и считаются от ШИРИНЫ родителя.
- Авторские названия дебютов сохраняем (переименование — позже,
  централизованно через `src/data/names.ts`).
